## 성공 기준

1. **정상 흐름**: `docs/저작권-출처-수직슬라이스-설계.md`에 30~40분 플레이를 분 단위로 따라갈 수 있는 과거(회색) → 같은 장소 전환 → 현재(컬러) → `겹친 무대` 설득 배틀 흐름이 완결되어 있다.
2. **인과 및 구현 가능성**: 과거 행동 메뉴, 결과 태그, 현재의 맵·퍼즐·NPC·배틀 반영, 저장 체크포인트와 재개 위치가 모호하지 않은 표·규칙으로 연결되어 있다. 선량한 플레이어도 기본 문제와 충분한 게임 콘텐츠를 경험하며, 지름길은 피해량이 아니라 복구 종류와 부담을 늘린다.
3. **아동 안전·실패 대응**: 실제 사진 업로드·외부 공유·실제 인물 합성·침해 재현을 요구하지 않고, 본편 OX 퀴즈·도덕 점수·강제 오답을 사용하지 않는다. 실패 시 가까운 체크포인트, 단서 보존, 2회 반디 힌트, 3회 탄막 완화가 명시된다.
4. **정체성 회귀 방지**: 방탈출형 설득 어드벤처, 마음 조각 배틀, 반디=영이, 고요의 비상 정지 역할, 네 엔딩, 순수 Canvas/PWA, 현재 컬러·과거 회색 계약을 보존하며 원본 저장소를 변경하지 않는다.
5. **범위 통제**: 첫 슬라이스의 Must/Should/Deferred 경계, 재사용할 기존 데이터 표면, 다음 네 장으로 확장할 공통 장 템플릿, 구현 수락 조건과 플레이테스트 시나리오가 포함된다.

## 검증 시나리오

- 시나리오 A: 처음 플레이하는 초등 고학년이 지도 설명만 보고 세 창작실을 탐색하고, 윤리적 방법·타협·즉시 복원 중 하나를 스스로 선택한 뒤 현재의 결과를 이해할 수 있는지 문서 순서대로 QA-by-read 한다.
- 시나리오 B: 모든 지름길, 모든 신중한 선택, 혼합 선택을 각각 대입해 결과 태그가 현재 퍼즐과 `겹친 무대`에 빠짐없이 도달하고 진행 막힘이 없는지 상태 행렬로 검토한다.
- 시나리오 C: 큰 글씨·효과 줄이기·저사양·모바일 세로/가로·TTS·중간 종료/재개 조건에서 잘림, 번쩍임, 입력 독점, 상태 손실이 생기지 않는지 요구사항별로 검토한다.
- 시나리오 D: 기준서와 기존 메멘토 설계에 대해 금지 어휘, 퀴즈 혼입, 파괴형 결말, 반디의 의도적 거짓말, 원본 저장소 변경이 없는지 회귀 검토한다.

## 초기 발견

- 권위 문서는 `CLAUDE.md`, `docs/기준서-방탈출-리부트.md`, `DESIGN.md` 순으로 적용한다.
- 기존 저작권 표면은 `따라`, `ev_maker`, `ev_source`, `ev_myvoice`, 저작권 설득 프로필이다. 새 슬라이스는 이를 폐기하지 않고 공동 창작관의 인물·단서로 재배치한다.
- 기존 메멘토 구현은 기록 열람과 시간순 배열이 중심이다. 새 설계는 과거 행동을 실제로 플레이하고 현재 결과를 수습하는 인과 루프로 확장하되, 기존 저장 네임스페이스와 반디/고요/엔딩 계약은 유지한다.

## 2026-08-28 · 사전 레드팀과 충돌 해소

- 공식 메멘토 문서의 `현재 정방향 + 기록 컷신`과 새 `과거 플레이 → 현재 결과`는 충돌한다. 해결: 원래 모험은 그대로 두고, 미리보기의 `메멘토 시간선 체험` 안에 **독립 수직 슬라이스 경로**를 둔다. 첫 슬라이스가 검증되기 전에는 기존 다섯 장을 덮어쓰지 않는다.
- `겹친 무대`는 사람이 아니지만 마음 조각 배틀의 정체성을 버리지 않는다. 해결: 무대를 파괴 대상이나 가짜 인물로 등록하지 않고, 창작자의 목소리와 `따라`의 마음이 겹쳐 굳은 **장소형 마음 조각**으로 정의한다. 기존 턴제 입력·마음의 파도·열림 문법은 재사용하되, 완료 어댑터는 기존 `mercy`, 랭크, `defeated`에 쓰지 않는다.
- 기존 문서에는 메뉴 폐기안과 4메뉴 유지안이 함께 있다. 실제 코드와 최신 `CLAUDE.md`를 따라 `말 걸기 · 증거 보여주기 · 가만히 듣기 · 마음 안아 주기`의 4메뉴를 유지하고, 상대 턴의 행동 패턴으로 레이어 분리 플레이를 제공한다.
- 이 슬라이스는 싱글 플레이만 지원한다. `한 쌍`은 두 플레이어가 아니라 과거/현재 장면 한 쌍을 뜻한다.
- 외부 통신은 모두 허구의 고정 데이터다. 실제 메일·메신저·사진·음원·파일 선택·자유 입력·클립보드·업로드·전송을 추가하지 않는다.
- 저작권 학습 규칙은 `만든 사람 확인 → 이용 조건 확인 → 변경·전시 범위 확인 → 출처와 AI 도움 기록`의 네 단계로 잠근다. 출처 표시는 허락을 대신하지 않는다. CCL 자료는 저작자·출처·조건을 표시하고 허용 범위 안에서만 이용한다는 한국저작권위원회 공유마당 안내를 근거로 한다.
- 지름길의 현재 효과는 벌이나 추가 피해가 아니라 `확인·표시·대체` 작업이다. 지름길이 과거 전시 슬롯을 즉시 채웠다는 실제 이점도 일지에 사실로 남긴다. 신중한 선택에도 동일한 기본 수리와 전체 피날레가 있다.
- 추가 수리는 `shortcutTags`에서 순수 파생하고 직접 가산하지 않는다. 그림·음악·글마다 최대 추가 수리 하나, 출처 원장 상태로 최대 하나를 더해 분기 폭증과 진행 막힘을 방지한다.
